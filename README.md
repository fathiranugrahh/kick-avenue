## About

Kick Avenue is the landing page for a sneaker and streetwear shop. It showcases trending sneakers and apparel in a clean product grid — and customers order through the floating WhatsApp button.

## Features

- 👟 **Trending sneakers** — New Balance 530, 2002R, 1906R; Adidas Ultraboost, Ultraboost 22, Gazelle; Puma Suede
- 👕 **Apparel** — Nike hoodies, KICK AVENUE tote bag and tees, tactical vest, Essentials hoodie
- 💬 **WhatsApp order button** — floating button that opens a chat to order
- 🖼️ **Product cards** — hover zoom, responsive grid
- 📱 **Fully responsive** — mobile-first layout

## Getting Started

```bash
# Clone the repository
git clone https://github.com/fathiranugrahh/kick-avenue.git
cd kick-avenue

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
